### 🎬 FilmRec — Movie Recommendation Engine

A full-stack movie recommendation platform built with React and Spring Boot.

**Highlights:**

* REST APIs for movie browsing, ratings, authentication, and recommendations
* JWT-based authentication using Spring Security
* TMDB API integration for movie metadata
* Movie information including posters, genres, directors, actors, and ratings
* MongoDB and TiDB Cloud integration
* Frontend deployed on Vercel
* Backend deployed on Render

**Tech:** `React` `Spring Boot` `JWT` `MongoDB` `TiDB Cloud`

### 📝 Lowkey — Personal Journaling & Mood Analytics

A full-stack journaling platform focused on secure journal management and mood analytics.

**Highlights:**

* REST API built with Spring Boot

* User-specific authorization for journal CRUD operations

* Google Gemini AI integration for personalized mood insights
